# Manuel utilisateur

Le site est disponible sur `http://localhost:5173`.

## Compte

Pour créer un compte :

1. Cliquer sur **Inscription**.
2. Remplir le prénom, le nom, l'email et le mot de passe.
3. Confirmer le mot de passe puis valider.

Pour se connecter, utiliser le bouton **Connexion** avec son email et son mot de passe.

## Listes

La page **Mes listes** affiche les listes créées ou partagées avec l'utilisateur.

Pour créer une liste :

1. Cliquer sur **Créer une liste**.
2. Donner un nom à la liste.
3. Cliquer sur **Créer**.

Le créateur peut utiliser **Inviter** pour ajouter un utilisateur déjà inscrit. Les rôles disponibles sont lecteur, commentateur, éditeur et créateur.

## Lieux

Dans une liste, cliquer sur **Ajouter un lieu à la liste**. Le nom, l'adresse, la ville et le pays sont les informations principales.

Il est aussi possible de renseigner une catégorie, une description, des tags, un prix, des horaires, un statut et des coordonnées GPS.

Les statuts acceptés sont :

- `a_visiter`
- `visite`
- `favoris`

Pour les photos, saisir les liens des images séparés par des virgules.

## Recherche

Les lieux peuvent être filtrés par texte, ville, pays, catégorie, note, prix ou statut.

Mettre la note ou le prix à `0` désactive le filtre correspondant.

## Avis

Cliquer sur un lieu pour voir sa fiche. Un utilisateur autorisé peut ajouter une note de 1 à 5 et un commentaire.

Un nouvel avis du même utilisateur remplace le précédent. La moyenne du lieu est recalculée automatiquement.

## Déconnexion

Cliquer sur **Déconnexion** dans le menu pour fermer la session.
