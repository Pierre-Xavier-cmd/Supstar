# Supstar

Application web de gestion et de partage de lieux.

## Lancer le projet

```bash
JWT_SECRET=une_cle docker compose up --build
```

Le site est ensuite disponible sur `http://localhost:5173`.

Pour arrêter :

```bash
docker compose down
```
